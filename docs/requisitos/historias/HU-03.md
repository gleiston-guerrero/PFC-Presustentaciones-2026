# HU-03: Asignación de jurados (RF-03)

**Prioridad MoSCoW:** Must

## Formato Connextra
> Como **coordinador de carrera**,
> quiero **asignar 3 docentes jurados a una solicitud**,
> para **conformar el tribunal calificador de la pre-sustentación**.

## Checklist INVEST

| Criterio | Cumple | Nota |
|---|---|---|
| Independent | ✅ | Depende de que exista la solicitud (HU-02), no de otras HUs |
| Negotiable | ✅ | El algoritmo de selección de jurados es negociable |
| Valuable | ✅ | Sin tribunal no hay evaluación posible |
| Estimable | ✅ | Alcance acotado |
| Small | ✅ | Una sola operación de asignación masiva |
| Testable | ✅ | Cubierto por prueba automatizada real |

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Asignación de jurados
  Scenario: Asignación exitosa de 3 jurados
    Given una solicitud sin jurados asignados y 3 docentes disponibles
    When el coordinador envía POST /api/v1/jurados/asignar-masivo con los 3 docentes
    Then el sistema conforma el tribunal con exactamente 3 jurados
    And notifica a cada docente asignado

  Scenario: Intento de asignar menos de 3 jurados
    Given una solicitud sin jurados asignados
    When el coordinador intenta asignar solo 2 docentes
    Then el sistema rechaza la operación
```
