# HU-05: Evaluación por rúbrica (RF-05)

**Prioridad MoSCoW:** Must

## Formato Connextra
> Como **jurado calificador**,
> quiero **evaluar cada criterio de la rúbrica institucional (Propuesta, Documento, Exposición)**,
> para **que el sistema calcule automáticamente la calificación ponderada del estudiante**.

## Checklist INVEST

| Criterio | Cumple | Nota |
|---|---|---|
| Independent | ✅ | Depende del tribunal (HU-03) y del cronograma (HU-04) |
| Negotiable | ✅ | Los pesos exactos de la rúbrica son parametrizables |
| Valuable | ✅ | Es el núcleo académico del sistema |
| Estimable | ✅ | Alcance acotado |
| Small | ✅ | Una evaluación por criterio, agregada automáticamente |
| Testable | ✅ | Cubierto por prueba automatizada real |

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Evaluación por rúbrica
  Scenario: Evaluación completa de un jurado
    Given un jurado asignado a una solicitud con cronograma vigente
    When envía POST /api/v1/evaluaciones/evaluar con puntajes para cada criterio de la rúbrica
    Then el sistema calcula la nota ponderada de ese jurado
    And, cuando todos los jurados han evaluado, calcula la nota final agregada

  Scenario: Intento de evaluar fuera de rango
    Given un criterio de rúbrica con puntaje máximo definido
    When el jurado envía un puntaje mayor al máximo permitido
    Then el sistema rechaza la evaluación
```
