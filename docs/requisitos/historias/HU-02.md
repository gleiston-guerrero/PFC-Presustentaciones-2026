# HU-02: Registro de solicitud de pre-sustentación (RF-02)

**Prioridad MoSCoW:** Must

## Formato Connextra
> Como **estudiante egresado**,
> quiero **registrar mi tema de titulación y adjuntar el anteproyecto en PDF**,
> para **iniciar el proceso formal de revisión y agendamiento de mi pre-sustentación**.

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Registro de solicitud de pre-sustentación
  Scenario: Registro exitoso
    Given un estudiante autenticado sin una solicitud activa
    When envía POST /api/solicitudes con título de tema y modalidad
    Then el sistema crea la solicitud en estado inicial
    And la solicitud queda asociada al estudiante autenticado (no a un ID recibido del cliente)

  Scenario: Intento de doble registro
    Given un estudiante que ya tiene una solicitud activa
    When intenta registrar una segunda solicitud
    Then el sistema rechaza la operación con un mensaje explícito
```
