# HU-12: Carga y verificación de anteproyecto (RF-12)

**Prioridad MoSCoW:** Must

## Formato Connextra
> Como **estudiante**,
> quiero **subir el PDF de mi anteproyecto y que el sistema verifique su integridad**,
> para **asegurarme de que el documento que el tribunal revisará es exactamente el que yo envié, sin alteraciones**.

## Checklist INVEST

| Criterio | Cumple | Nota |
|---|---|---|
| Independent | ✅ | Depende de que exista la solicitud (HU-02) |
| Negotiable | ✅ | El algoritmo de hash (SHA-256) es un detalle negociable |
| Valuable | ✅ | Garantiza integridad documental del entregable académico central |
| Estimable | ✅ | Alcance acotado |
| Small | ✅ | Subida + verificación de hash |
| Testable | ✅ | Cubierto por prueba automatizada real |

## Criterios de aceptación (Gherkin)

```gherkin
Feature: Carga y verificación de anteproyecto
  Scenario: Carga exitosa
    Given un estudiante con una solicitud activa sin anteproyecto cargado
    When envía POST /api/v1/anteproyectos/enviar/{solicitudId} con un PDF
    Then el sistema calcula y almacena el hash SHA-256 del archivo
    And el anteproyecto queda en estado "Enviado"

  Scenario: Verificación de integridad
    Given un anteproyecto cargado con hash almacenado
    When el sistema o un docente solicita GET /api/v1/anteproyectos/verificar/{solicitudId}
    Then el sistema recalcula el hash del archivo en disco
    And lo compara contra el hash almacenado usando comparación en tiempo constante (MessageDigest.isEqual)

  Scenario: Detección de alteración del archivo
    Given un archivo en disco modificado después de la carga original
    When se ejecuta la verificación de integridad
    Then el sistema reporta que la integridad NO se verifica
```

## Trazabilidad

- **Módulo backend:** Anteproyectos (`ProposalController`, `ProposalServiceImpl`)
- **Endpoint:** `POST /api/v1/anteproyectos/enviar/{solicitudId}`, `GET /api/v1/anteproyectos/verificar/{solicitudId}`
- **Prueba automatizada real:** ✅ [`backend/src/test/java/.../services/ProposalServiceImplTest.java`](../../../backend/src/test/java/ec/edu/uteq/presustentaciones/services/ProposalServiceImplTest.java) (72% de cobertura de líneas real)
- **Evidencia empírica adicional:** [`../../mediciones/sec/static-analysis/STATIC-ANALYSIS.md`](../../mediciones/sec/static-analysis/STATIC-ANALYSIS.md) — la comparación de hash de este módulo (`verificarIntegridad()`) se corrigió en la Fase 5 (vulnerable a timing attack con `String.equals()`, corregido a `MessageDigest.isEqual()`, hallazgo `UNSAFE_HASH_EQUALS` de find-sec-bugs)
